## Bahasa Indonesia

Filmanesia adalah platform penemuan film dan serial TV yang membantu pengguna menemukan tontonan berdasarkan genre, tahun, negara, rating, dan K-Drama. Antarmuka mendukung bahasa Indonesia, Inggris, dan Melayu melalui pilihan bahasa di navbar.

### Fitur

- Katalog film dan serial TV dari TMDB.
- Filter multi-pilihan: tahun, genre, negara, dan rating.
- Kategori K-Drama dengan filter Korea Selatan + Drama.
- Poster dan backdrop berukuran ringan untuk loading lebih cepat.
- Player dengan fallback server otomatis dan subtitle Indonesia sebagai default.
- Dark mode, responsive layout, pencarian, FAQ multibahasa, dan sitemap SEO.

### Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buat file `.env` berdasarkan variabel yang digunakan di `.env.example` atau konfigurasi deployment. Jalankan `npm run build` untuk membuat build production.

## English

Filmanesia is a movie and TV discovery platform. Users can browse titles by genre, year, country, rating, and K-Drama. The interface supports Indonesian, English, and Malay through the language selector in the navbar.

### Features

- TMDB-powered movie and TV catalog.
- Multi-select filters for year, genre, country, and rating.
- K-Drama category powered by South Korea + Drama filters.
- Lightweight posters and backdrops for faster loading.
- Player server fallback with Indonesian subtitles as the default.
- Dark mode, responsive layout, search, multilingual FAQ, and SEO sitemap.

### Local development

```bash
npm install
npm run dev
```

Configure the required environment variables, then run `npm run build` to verify a production build.

## Bahasa Melayu

Filmanesia ialah platform penemuan filem dan siri TV. Pengguna boleh mencari kandungan mengikut genre, tahun, negara, rating, dan K-Drama. Antara muka menyokong Bahasa Indonesia, English, dan Melayu melalui pilihan bahasa di navbar.

### Ciri-ciri

- Katalog filem dan siri TV berasaskan TMDB.
- Penapis berbilang pilihan untuk tahun, genre, negara, dan rating.
- Kategori K-Drama berdasarkan Korea Selatan + Drama.
- Poster dan backdrop ringan untuk pemuatan yang lebih pantas.
- Fallback server player dengan sari kata Indonesia sebagai lalai.
- Mod gelap, reka bentuk responsif, carian, FAQ berbilang bahasa, dan sitemap SEO.

### Pembangunan tempatan

```bash
npm install
npm run dev
```

Konfigurasikan pemboleh ubah persekitaran yang diperlukan dan jalankan `npm run build` untuk menyemak build production.
